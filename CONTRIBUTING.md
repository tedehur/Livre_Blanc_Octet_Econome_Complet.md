# Contributing

Merci de votre intérêt pour le projet Octet-Économe !

- Ouvrez une issue pour discuter d'une nouvelle fonctionnalité ou d'un bug.
- Forkez le dépôt et créez une branche à partir de `main` pour vos changements.
- Faites des commits clairs et petits, et ouvrez une Pull Request décrivant les changements.
- Respectez la licence MIT incluse dans le dépôt.
